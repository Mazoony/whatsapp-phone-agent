# WhatsApp agent

The WhatsApp runtime and its WhatsApp-specific broadcast, follow-up, incoming-message, and media-upload components live here.

From the repository root, start it with:

```powershell
npm run whatsapp
```

`npm start` remains a compatibility entry point. Shared services, configuration, lesson content, credentials, and runtime data remain at the repository root while they are used by more than one app.
